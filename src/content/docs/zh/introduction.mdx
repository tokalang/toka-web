---

Toka 是一门以静态安全、系统级控制与清晰表达为目标的原生系统编程语言，致力于让程序员与 AI 工具更可靠地构建、检查和维护软件。

无 GC、可预测的资源成本、PAL 静态检查，以及机器可读、可由编译器验证的语义
证据，共同支撑这一设计目标。

项目统一名称为 **Toka systems programming language**，官方源码位于
[`tokalang/toka`](https://github.com/tokalang/toka)。它不是历史上的 Toka Forth，
也不是其他同名或近似命名的 Toka / Toke 项目。

## 设计定位

Toka 从三项设计底线出发：无 GC、可预测的资源成本，强静态安全，以及面向 AI 的可验证语义。真正的设计问题是：在守住这些底线的前提下，语言语法和编译器纪律能否减少日常系统代码中的偶然复杂度。

这并不意味着不惜一切代价减少语法。Toka 追求的是在真实系统语义不被隐藏的前提下，触摸到所需的最小表层：每一处记号都应该让所有权、访问、表示、失败或控制流边界更容易被看见和审计。

这带来几条贯穿设计的原则：

- 源码应当展示真正发生的操作；
- 可变、重绑定、转移和可空不应在视觉上含混；
- 资源所有权应当显式到足以被静态检查；
- 编辑器和 AI 工具应当能够读取开发者所审阅边界对应的编译器事实；
- 底层表示应当可用，但不应把裸指针风格变成默认 API 形状。

这种安全态度在边界处是刻意保守的。Toka 不用降低安全性来换取更轻的表层；如果某种关系无法在局部证明，除非把完整生命周期演算暴露给用户，那么编译器应该拒绝这种模式，或要求程序写成更显式的结构。

## 核心模型

payload/handle 分离与 PAL 检查、确定性清理、资源契约及内建工具链共同支撑
上述目标，是其中一项表达机制。

Toka 把许多系统语言混在一起表达的东西拆成两层：

| 层级 | 含义 | 示例 |
| :--- | :--- | :--- |
| Payload / Soul | 被读取、写入、传参、匹配的对象内容 | `x`, `x.field`, `x = value` |
| Handle / Representation | 对象如何被访问、拥有、借用、共享或重绑定 | `&x`, `*x`, `^x`, `~x`, `*x = *y` |

裸名操作 payload。帽子操作 handle 身份。因此 `p = value` 和 `*p = *q` 是两类不同操作：前者写对象内容，后者重绑定 raw handle。

## 资源契约

Toka 使用紧凑标记表达不同资源事实：

| 标记 | 作用 |
| :--- | :--- |
| `#` | payload 可变；放在帽子后时表示 handle 具有重绑定权 |
| `?` | payload 类型可空状态 |
| `nul` | handle 可空标记 |
| `&` | 借用 / 引用 handle |
| `*` | 原始指针 handle |
| `^` | 独占所有权 handle |
| `~` | 共享所有权 handle |
| `cede` | 显式资源转移契约 |

普通对象参数使用逻辑上的原地捕获。函数需要 payload 视图时写 `x: T` 或 `x#: T`；只有函数确实需要 handle 本体时，才在参数名侧加帽子，例如为了转发或重绑定该 handle。

`cede` 既是权限，也是义务。如果函数签名请求 `cede`，函数体必须显式消费、转发、存储、返回，或以其他方式完成这条资源转移路径。

## 语言表面

当前实现包含具名 `shape` 构造、类 enum 变体、trait 与 `impl`、morphic 泛型、确定性清理、使用后缀 `!` 的 `Result` / `Option` 失败传播、`async` / `.await`、模式匹配，以及基于 LLVM 20 的原生编译。

## Toka 代码初探

```toka
import std/io::println

shape Resource(val: i32)

fn keep(cede r: Resource) -> Resource {
    return cede r
}

shape Rect (
    width: i32,
    height: i32
)

impl Rect {
    pub fn area(self) -> i32 {
        return self.width * self.height
    }
}

fn main() -> i32 {
    auto r = Rect(width = 10, height = 20)
    println("面积: {}", r.area())

    auto owned = Resource(val = 42)
    auto moved = keep(cede owned)

    if moved.val != 42 {
        return 1
    }
    return 0
}
```
